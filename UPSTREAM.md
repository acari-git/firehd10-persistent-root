# Upstream provenance

This repository builds on **SnuSnuRoot** by voidnullvalue. Nothing here
is a new exploit: the temporary-root chain is upstream's work, and this
repository contains the persistence + hardening layer developed on top
of it (plus the adaptation of that layer to firmware build
PS7331.4463N; upstream documents PS7331.4460N as its target).

## Per-file provenance of this repository

Origin key: **original** = written for this project (Oct–Nov 2026);
**forked** = derived from the upstream file named, with changes
summarized from the project's signed manifests and session records;
**upstream-lineage** = carried from upstream's chain, staged here in
its fielded (acceptance-verified) form. SHA-256 values are of the
files as staged, so they can be checked against the development
project's manifests (`app/manifest-v2.json`, `signer/manifest-signer.json`,
and the component manifests cited in the project records).
